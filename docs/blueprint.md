# **App Name**: Escuelas Seguras MVP

## Core Features:

- User Authentication & Role-Based Access: Allow users to log in (simulated) as 'Comunidad' (student, parent, neighbor) or 'Autoridad' (director, prefect, C5), granting access to specific features and content based on their role.
- Role-Specific Dashboards: Present distinct summary dashboards displaying key performance indicators (KPIs), quick views, and recent activity feeds relevant to either 'Comunidad' (personal summaries, local alerts) or 'Autoridad' (overall security status, global overview) users.
- Community Incident Reporting: Enable 'Comunidad' users to easily submit detailed incident reports including incident type, specific location (zone), a descriptive summary, and an optional photograph.
- AI-Powered Incident Response Tool: For 'Autoridad' users, an AI tool that analyzes submitted incident reports, extracting key information and suggesting recommended actions, resources, or communication strategies for efficient resolution.
- Interactive Perimeter Map: Display an interactive map for 'Autoridad' users, visualizing the school perimeter, fixed access points, and dynamic, live locations of reported incidents with contextual tooltips.
- Incident Management System: Provide 'Autoridad' users with a centralized list to view, filter, manage, and mark incident reports as resolved, facilitating timely responses.
- Access Control & Logging: Track and display a searchable log of entries and exits, including details about the person, their role, access point, and validation status, for 'Autoridad' users to monitor school traffic.

## Style Guidelines:

- Primary color: A vibrant Emerald Green (#10B981) to symbolize safety, growth, and community, prominent in interactive elements and branding. (HSL: 158, 85%, 39%)
- Background color: A soft, barely tinted minty green (#F0F6F3), creating a clean and calming canvas that complements the primary, reinforcing a secure and educational environment. (HSL: 158, 15%, 95%)
- Accent color: A lively Lime Green (#66BF66), chosen as an analogous hue (approximately 30 degrees to the left of the primary on the color wheel) to highlight calls-to-action and important interactive components, offering clear visual differentiation while maintaining harmony. (HSL: 128, 55%, 50%)
- Body and headline font: 'Inter' (sans-serif) for its modern, clear, and highly readable qualities across various screen sizes and text densities, reflecting the platform's objective and efficient nature. Note: currently only Google Fonts are supported.
- Utilize a consistent set of 'Font Awesome Solid' icons for functionality and status indicators, providing clear and recognizable visual cues throughout the application.
- Responsive layout designed for desktop and mobile, featuring a persistent sidebar for main navigation (on larger screens) and dynamic content areas, leveraging cards and grid structures for organized information display.
- Subtle UI animations including fade-ins for content sections, a pulsing effect for high-priority alerts, and bounce animations for map pins to draw attention to critical events.
